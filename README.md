# JellyFish

一个自用的 SillyTavern 小工具：在聊天导航栏下方保留一条紧凑横栏，把魔法棒和左下菜单里的常用功能放到手边，并提供当前楼层回顶、到底部按钮。

## 功能

- 在横栏中添加一个或多个快捷功能，来源包括魔法棒和左下菜单。
- 快捷功能可以添加、移除和前移／后移排序。
- 横栏右侧固定紧凑的上下箭头，分别对应当前楼层回顶和到底部。
- 原扩展尚未加载时保留快捷配置，并标记“未检测到原入口”。
- 配置保存在 SillyTavern 的扩展设置中。
- 不复制、不修改原扩展功能，只调用对应区域的原入口。

## 安装

在 SillyTavern 的扩展安装界面填写：

```text
https://github.com/besoecho/JellyFish
```

安装后刷新页面。

## 使用

1. 点击横栏最左侧的设置按钮。
2. 在“可添加的功能”中按来源找到目标，点击“添加”。
3. 在“横栏里的快捷功能”中调整顺序或移除入口。
4. 点击横栏中的图标即可调用对应功能；窄屏下只显示图标，长按或悬停可查看名称。

JellyFish 识别魔法棒和左下菜单中带有元素 ID 的标准菜单项与按钮。输入框、滑块等设置控件不属于可点击功能，不会出现在列表中；使用非标准菜单结构的第三方扩展可能需要单独适配。

## 开发

原生 JavaScript ES Module，无构建步骤。浏览器回归测试：

```bash
python3 tests/smoke.py
```

测试需要 Python Playwright 和 Chromium。
