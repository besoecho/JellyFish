# JellyFish

一个自用的 SillyTavern 小工具：在聊天导航栏下方保留一条横栏，把右下角魔法棒里的常用功能放到手边，并提供当前楼层回顶、到底部按钮。

## 功能

- 在横栏中添加一个或多个魔法棒快捷功能。
- 快捷功能可以添加、移除和前移／后移排序。
- 横栏右侧固定 `↑`（当前楼层回顶）和 `↓`（当前楼层到底部）。
- 原扩展尚未加载时保留快捷配置，并标记“未检测到原入口”。
- 配置保存在 SillyTavern 的扩展设置中。
- 不复制、不修改原扩展功能，只调用魔法棒里的原按钮。

## 安装

在 SillyTavern 的扩展安装界面填写：

```text
https://github.com/besoecho/JellyFish
```

安装后刷新页面。

## 使用

1. 点击横栏最左侧的设置按钮。
2. 在“魔法棒里的可用功能”中点击“添加”。
3. 在“横栏里的快捷功能”中调整顺序或移除入口。
4. 点击横栏中的图标即可调用对应功能；窄屏下只显示图标，长按或悬停可查看名称。

JellyFish 当前识别魔法棒菜单中带有元素 ID 的标准 `.list-group-item` 入口。若某个第三方扩展使用完全不同的菜单结构，可能不会出现在可选列表中。

## 开发

原生 JavaScript ES Module，无构建步骤。浏览器回归测试：

```bash
python3 tests/smoke.py
```

测试需要 Python Playwright 和 Chromium。
